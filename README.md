# Desafio Matemático — 6º ano

Jogo educativo de Matemática para estudantes do 6º ano do Ensino Fundamental.

## Como jogar
1. Abra `index.html` no navegador ou publique o projeto com GitHub Pages.
2. Clique em **Começar o jogo**.
3. Escolha uma alternativa em cada pergunta.
4. Leia a explicação e veja a pontuação final.

## Tecnologias
- HTML5: estrutura semântica.
- CSS3: cores, layout responsivo e acessibilidade visual.
- JavaScript: perguntas, respostas, pontuação e telas.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `desafio-matematico-6ano`.
2. Envie `index.html`, `style.css` e `script.js` para a página inicial do repositório.
3. Vá a **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione `main` e `/ (root)` e clique em **Save**.
6. O GitHub mostrará o link publicado na mesma página do Pages. Copie esse link para a entrega.

## Disciplina e público-alvo
Matemática, alunos do 6º ano do Ensino Fundamental, aproximadamente 11 a 12 anos.
